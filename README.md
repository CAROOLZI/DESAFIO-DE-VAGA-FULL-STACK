# DESAFIO-DE-VAGA-FULL-STACK

# Teste Prático - Iniflex (Prothera Tecnologia)

Repositório destinado à resolução do teste prático de programação para a vaga de Desenvolvedor(a) Full Stack. O objetivo do projeto é gerenciar uma lista de funcionários, aplicando regras de negócio, cálculos matemáticos e formatação de dados.

## 💻 Tecnologias e Práticas Utilizadas
- **Java** 
- **Orientação a Objetos** (Herança e Encapsulamento)
- **API de Datas do Java 8+** (`LocalDate`, `Period`, `DateTimeFormatter`)
- **Manipulação Financeira Segura** (`BigDecimal` e `RoundingMode`)
- **API de Streams e Expressões Lambda** para filtragem, ordenação e agrupamentos (`Collectors.groupingBy`)
- **Maven** para gerenciamento de dependências e execução.
